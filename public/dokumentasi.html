1.5 Laporan Masalah (Sengketa / Dispute)

Sistem resolusi konflik buyer-seller dengan escrow & refund otomatis

📊Alur Status Dispute

open → admin_reviewing → buyer_won / seller_won → buyer_shipping_back → seller_received_back → refunded / closed

🔧Aksi Panel Resolusi Admin

  • Tandai "Sedang Ditinjau" → kirim notifikasi ke chat
  • Putuskan pemenang: Pembeli atau Penjual
  • Tambahkan catatan admin
  • Admin Konfirmasi Barang Diterima (bypass alur normal)
  • Force Refund langsung ke pembeli
  • Lihat log aktivitas dispute lengkap

💬Chat Terintegrasi di Detail

  • Percakapan buyer ↔ seller tampil langsung di halaman
  • Admin kirim pesan intervensi (masuk room chat buyer-seller)
  • Pesan admin ditampilkan sebagai bubble ungu terpusat
  • Auto-refresh percakapan setiap 15 detik
  • Deduplication: pesan identik tidak tampil dobel

💰Alur Refund Otomatis (Pembeli Menang)

Admin putuskan → Pembeli menang ↓ Notifikasi ke chat: "Silakan kirim barang kembali ke penjual" ↓ Pembeli input nama driver + plat nomor di aplikasi Android ↓ Penjual konfirmasi menerima barang kembali ↓ Dana OTOMATIS dikreditkan ke MeyPay Wallet pembeli ↓ Status transaksi: disputed_refunded ✅
Keamanan: Semua operasi wallet menggunakan DB transaction + lockForUpdate() untuk mencegah double-refund concurrent.

2.1 Autentikasi & Keamanan

👤Autentikasi Pengguna

  • Login email + password → token Sanctum
  • Registrasi akun baru
  • Lupa password via OTP email
  • Token disimpan di SharedPreferences (SessionManager)

🛡️Keamanan Token

  • Auto-logout + redirect ke Login saat token expired (401)
  • Global OkHttp interceptor mendeteksi 401 semua endpoint
  • Session dibersihkan (SessionManager.logoutUser())
  • Semua activity stack dibersihkan saat logout

2.3 Pembayaran & MeyPay Wallet

💳Metode Pembayaran yang Didukung

MetodeAlurVerifikasi
MeyPay WalletBayar langsung dari saldo MeyPay, verify PINOtomatis real-time
Transfer BankUpload foto bukti pembayaranManual oleh Admin
QRISScan QR code yang di-generate sistemOtomatis via gateway
Virtual AccountTransfer ke nomor VA yang di-generateOtomatis via gateway
CODBayar saat barang diterimaDriver konfirmasi

💰MeyPay Wallet

  • Lihat saldo tersedia & saldo pending (escrow)
  • Top-up saldo MeyPay
  • Riwayat transaksi wallet lengkap
  • Verify PIN sebelum transaksi
  • Dana pending = uang yang ditahan untuk pesanan aktif

📊Alur Dana Escrow

  • Pembeli bayar → dana masuk pending_balance
  • Pesanan selesai (received) → dana ke penjual (90%)
  • Platform fee 10% dicatat sebagai PlatformEarning
  • Dispute/refund → dana kembali ke pembeli
  • Penjual tarik saldo → ke rekening eksternal

2.4 Riwayat Pesanan & Laporan Masalah

📋Tombol Aksi per Status Pesanan (Pembeli)

StatusTombol yang MunculAksi
waiting_paymentBayar Sekarang / Upload Bukti BayarBuka PaymentActivity atau picker gambar
paid_verifiedLihat InvoiceBuka InvoiceActivity
shippedKonfirmasi Diterima + Ajukan Laporan MasalahKonfirmasi atau buka DisputeDetailActivity
disputed📦 Kirim Barang KembaliBuka DisputeDetailActivity (form resi)
disputed_refunded✅ Lihat Detail RefundLihat konfirmasi refund di DisputeDetailActivity
completedLihat InvoiceBuka InvoiceActivity
cancelledHapus PesananHapus dari riwayat

⚠️DisputeDetailActivity — Alur Lengkap Pembeli

Tap "Ajukan Laporan Masalah" (status: shipped) ↓ DisputeDetailActivity terbuka ↓ [Belum ada dispute?] → Dialog: "Isi alasan laporan" → POST /api/disputes/{txId} → Laporan terkirim ke admin → Status: OPEN ↓ [open / admin_reviewing] → Info: "Laporan sedang ditinjau admin" ↓ [buyer_won] → Form INPUT: Nama Driver + Plat Nomor → POST /disputes/{id}/buyer-ship-back ↓ [buyer_shipping_back] → Info resi + menunggu konfirmasi penjual ↓ [seller_received_back] → "Dana sedang diproses..." ↓ [refunded] → "Dana masuk MeyPay Wallet kamu ✅"

3. Alur Lengkap Transaksi Marketplace

End-to-end flow dari pembelian hingga penyelesaian

✅Alur Normal (Tanpa Masalah)

PEMBELI PENJUAL ADMIN │ │ │ ├─ Pilih produk & checkout │ │ ├─ Bayar (MeyPay/Transfer) │ │ │ │ [Verifikasi pembayaran] │ Notifikasi pesanan baru │ │ ├─ Kemas produk │ │ ├─ Input driver + plat nomor│ │ ├─ Tandai "Dikirim" │ ├─ Konfirmasi barang diterima │ │ │ │ [Lepas dana ke penjual] └─ Transaksi SELESAI ──────────┘ │ Platform fee 10% dicatat

⚠️Alur Dispute & Refund (Pembeli Menang)

PEMBELI PENJUAL ADMIN │ │ │ ├─ Ajukan laporan masalah │ │ │ (saat status: shipped) │ │ │ │ ├─ Tinjau laporan │ │ ├─ Tandai "Sedang Ditinjau" │ │ └─ Putuskan: PEMBELI MENANG │ │ │ ├─ Input driver + plat nomor │ │ ├─ Kirim barang kembali ───────► │ │ Konfirmasi terima barang │ │ │ │ └─ Dana OTOMATIS masuk ◄───────┴──────────────────────────┘ MeyPay Wallet (100%) Status: disputed_refunded ✅

💰Alur Dispute (Penjual Menang)

Admin putuskan: PENJUAL MENANG ↓ Dana dilepas dari escrow pembeli ↓ Penjual menerima 90% dari total transaksi ↓ 10% masuk sebagai Platform Fee (PlatformEarning) ↓ Transaksi ditandai: completed Pembeli tidak bisa memberikan rating
